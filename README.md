# Altayar - تطبيق السياحة والسفر

## نظرة عامة

قمت بتطوير تطبيق Altayar كمنصة متكاملة للسياحة والسفر باستخدام React Native. يوفر التطبيق تجربة مستخدم سلسة لحجز الرحلات السياحية، إدارة العضويات، ومتابعة الحجوزات.

## المميزات الرئيسية

### إدارة المستخدم
- نظام تسجيل دخول وتسجيل حساب جديد
- إدارة الملف الشخصي
- نظام إشعارات متكامل

### الحجوزات والرحلات
- استعراض الرحلات السياحية المتاحة
- حجز الرحلات والباقات السياحية
- متابعة حالة الحجوزات

### العضويات والباقات
- باقات عضوية متنوعة
- عروض وخصومات حصرية
- نظام تقييمات ومراجعات

### الإعدادات
- دعم اللغة العربية والإنجليزية
- وضع ليلي ونهاري
- إعدادات الإشعارات

## التقنيات المستخدمة

### الأساسية
- **React Native** 0.76.3
- **TypeScript** للكتابة الآمنة
- **React Navigation** للتنقل بين الشاشات

### إدارة الحالة
- **Zustand** لإدارة الحالة العامة
- **React Query** للتعامل مع البيانات من الخادم
- **React Hook Form** مع **Yup** للنماذج والتحقق

### واجهة المستخدم
- **React Native Paper** للمكونات
- **React Native Animatable** للتحريكات
- **React Native Vector Icons** للأيقونات
- **React Native Linear Gradient** للتدرجات

### الخدمات
- **Axios** للاتصال بالخادم
- **Async Storage** للتخزين المحلي
- **React Native Keychain** للحفظ الآمن

## هيكل المشروع

```
src/
├── components/     # المكونات القابلة لإعادة الاستخدام
├── constants/      # الثوابت والقيم الافتراضية
├── contexts/       # سياقات React (اللغة، السمة)
├── hooks/          # الـ Hooks المخصصة
├── navigation/     # إعدادات التنقل
├── screens/        # شاشات التطبيق
│   ├── auth/       # شاشات المصادقة
│   ├── bookings/   # شاشات الحجوزات
│   ├── home/       # الشاشة الرئيسية
│   ├── memberships/# شاشات العضويات
│   ├── packages/   # شاشات الباقات
│   ├── profile/    # شاشات الملف الشخصي
│   ├── settings/   # شاشات الإعدادات
│   └── trips/      # شاشات الرحلات
├── services/       # خدمات API
├── stores/         # مخازن Zustand
└── types/          # تعريفات TypeScript
```

## المتطلبات

- Node.js 18.0.0 أو أحدث
- React Native CLI
- Android Studio (للتطوير على أندرويد)
- Xcode (للتطوير على iOS - يتطلب macOS)

## التثبيت والتشغيل

### 1. تثبيت الاعتماديات

```bash
npm install
```

### 2. تشغيل التطبيق

**للأندرويد:**
```bash
npm run android
```

**لـ iOS:**
```bash
npm run ios
```

### 3. تشغيل خادم Metro

```bash
npm start
```

## الأوامر المتاحة

| الأمر | الوصف |
|-------|-------|
| `npm run android` | تشغيل التطبيق على أندرويد |
| `npm run ios` | تشغيل التطبيق على iOS |
| `npm start` | تشغيل خادم Metro |
| `npm test` | تشغيل الاختبارات |
| `npm run lint` | فحص الكود |
| `npm run build:android` | بناء نسخة الإنتاج للأندرويد |
| `npm run clean:android` | تنظيف ملفات البناء |
| `npm run reset:cache` | إعادة تعيين الذاكرة المؤقتة |
