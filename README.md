# Altayar - تطبيق السفر والسياحة ✈️

مرحباً بكم في مشروع **الطيار** - تطبيق متكامل للسفر والسياحة مبني باستخدام React Native.

---

## 📱 نبذة عن المشروع

قمت بتطوير هذا التطبيق ليكون منصة شاملة تخدم المسافرين والشركاء السياحيين على حد سواء. الفكرة الأساسية هي توفير تجربة سفر متكاملة تبدأ من البحث عن الباقات السياحية وتنتهي بمشاركة تجارب السفر مع الآخرين.

## 🚀 تشغيل المشروع

### المتطلبات
- Node.js >= 18.0.0
- npm أو yarn
- Android Studio (لتطبيق Android)
- Xcode (لتطبيق iOS - على macOS فقط)
- JDK 17

### خطوات التثبيت

1. **استنساخ المشروع**
```bash
git clone https://github.com/OmarAhmed-123/Altayar.git
cd Altayar
git checkout ReactNative_0.82
```

2. **تثبيت الحزم**
```bash
npm install --legacy-peer-deps
```

3. **تشغيل Metro Bundler**
```bash
npm start
```

4. **تشغيل التطبيق**

للأندرويد:
```bash
npm run android
```

للـ iOS:
```bash
cd ios && pod install && cd ..
npm run ios
```
