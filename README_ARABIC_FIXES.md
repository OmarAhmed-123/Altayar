# إصلاحات دعم اللغة العربية في ملفات PDF

## المشاكل التي تم حلها

### 1. دعم اللغة العربية في كارت العضوية
- ✅ تحديث `utils/pdfGenerator.js` لاستخدام خطوط Cairo عند توفرها
- ✅ إضافة دعم RTL (من اليمين لليسار) للنصوص العربية
- ✅ استخدام النص العربي مباشرة عند توفر خطوط Cairo

### 2. دعم اللغة العربية في التقارير الشخصية
- ✅ تحديث `controllers/reportController.js` لاستخدام خطوط Cairo
- ✅ تحسين عرض النصوص العربية في جميع أقسام التقرير
- ✅ إضافة ترجمة تلقائية كبديل عند عدم توفر الخطوط

### 3. إصلاح مشكلة فتح ملفات PDF
- ✅ تغيير `Content-Disposition` من `attachment` إلى `inline` للعرض في المتصفح
- ✅ إضافة دعم `Accept-Ranges` للعرض الجزئي
- ✅ تحسين رؤوس CORS للسماح بالعرض من أي مصدر

### 4. تحسين نظام الخطوط
- ✅ تحديث `utils/pdfFontHelper.js` للبحث عن الخطوط في عدة مسارات
- ✅ إضافة رسائل تحذير واضحة عند عدم توفر الخطوط
- ✅ تحسين معالجة الأخطاء

## خطوات التثبيت

### 1. تثبيت خطوط Cairo

#### الطريقة التلقائية:
```bash
node scripts/downloadCairoFonts.js
```

#### الطريقة اليدوية:
1. قم بزيارة: https://fonts.google.com/specimen/Cairo
2. اضغط على "Download family"
3. استخرج ملف ZIP
4. انسخ الملفات التالية إلى `assets/fonts/`:
   - `Cairo-Regular.ttf`
   - `Cairo-Bold.ttf`

### 2. التحقق من التثبيت

بعد إضافة الخطوط، تأكد من وجود الملفات:
```bash
ls assets/fonts/
# يجب أن ترى:
# - Cairo-Regular.ttf
# - Cairo-Bold.ttf
```

### 3. اختبار التطبيق

```bash
# ابدأ الخادم
npm start

# اختبر إنشاء PDF كارت العضوية
# اختبر إنشاء PDF التقرير الشخصي
```

## الملفات المعدلة

1. `utils/pdfFontHelper.js` - تحسين نظام الخطوط
2. `utils/pdfGenerator.js` - دعم العربية في كارت العضوية
3. `controllers/reportController.js` - دعم العربية في التقارير
4. `scripts/downloadCairoFonts.js` - سكريبت تحميل الخطوط
5. `app.yaml` - إعدادات النشر على Google Cloud

## ملاحظات مهمة

- **بدون خطوط Cairo**: سيتم استخدام Helvetica كبديل، لكن النصوص العربية قد تظهر كرموز
- **مع خطوط Cairo**: النصوص العربية ستظهر بشكل صحيح مع دعم RTL
- **الترجمة التلقائية**: عند عدم توفر الخطوط، سيتم ترجمة النصوص العربية تلقائياً للإنجليزية

## استكشاف الأخطاء

### النصوص العربية تظهر كرموز
- تأكد من وجود خطوط Cairo في `assets/fonts/`
- تحقق من السجلات (logs) لمعرفة ما إذا تم تحميل الخطوط بنجاح

### ملفات PDF لا تفتح في المتصفح
- تحقق من رؤوس HTTP في `controllers/reportController.js`
- تأكد من أن `Content-Disposition` مضبوط على `inline` للعرض

### خطأ في تحميل الخطوط
- تحقق من المسارات في `utils/pdfFontHelper.js`
- تأكد من صلاحيات القراءة للملفات

## النشر على Google Cloud

قبل النشر، تأكد من:
1. إضافة خطوط Cairo إلى المشروع
2. تحديث `app.yaml` مع متغيرات البيئة الصحيحة
3. اختبار التطبيق محلياً أولاً

راجع `DEPLOYMENT.md` للتفاصيل الكاملة.
